# WWG 1.0.0

웹 ChatGPT를 내 컴퓨터에 연결해 파일과 명령을 실행하는 앱입니다.

## 기능

- 웹 ChatGPT 맞춤형 MCP 서버 등록과 터널 연결
- 여러 접근 폴더에서 파일 읽기·생성·수정·삭제
- AI가 접근을 허용한 프로젝트·폴더 목록과 경로 조회
- macOS·Windows 명령 실행과 폴더 간 대량 파일 이동·삭제
- 받은 요청, 실행 결과, 차단 사유를 실행 로그에 표시하고 내부에 최대 1,000개 보관
- 여러 파일·명령 요청을 작업으로 묶고 상태 조회·중지
- 수동승인이 필요한 요청에만 승인·거절 버튼 표시
- 자동승인과 일시 정지, 실행 중인 명령 중지
- `.env*`와 허용 범위 밖 접근 차단
- 기존 OS 환경변수의 이름만 허용하고 요청한 변수만 전달
- macOS 메뉴 막대에서 연결·실행 로그·승인 방식 조작
- Windows 무설치형 EXE 또는 ZIP으로 실행

## 사용방법

처음 실행하면 개인정보 및 데이터 처리 안내를 표시합니다. **안내 확인 후 사용**을 선택해야 폴더 접근·터널 연결·MCP 도구 실행을 시작할 수 있습니다. 기존 설치도 새 안내를 확인하며 기존 자동승인은 수동으로 전환됩니다. 안내는 **접근 설정**에서 다시 확인할 수 있습니다.

1. macOS는 DMG로 WWG를 설치합니다. Windows는 무설치형 EXE를 바로 실행하거나 ZIP을 풀고 WWG.exe를 실행합니다.
   macOS는 창을 닫아도 메뉴 막대에 남습니다. Windows는 창을 닫으면 앱·터널·실행 중인 명령을 종료합니다.
2. 상단의 **접근 폴더**에서 사용할 폴더를 선택합니다. 여러 폴더를 선택할 수 있습니다. 연결된 ChatGPT에 접근 가능한 프로젝트 목록을 확인해 달라고 요청할 수 있습니다.
3. **ChatGPT 연결**에서 터널을 연결합니다. API 키는 저장하지 않으므로 앱을 실행할 때마다 다시 입력합니다. 웹 ChatGPT의 **+ → 맞춤형 MCP 서버 만들기**로 WWG를 등록하고 **Connection → Tunnel**에 같은 터널을 지정해 생성을 완료합니다.
4. 웹 ChatGPT 대화에서 **@WWG**를 입력하고 WWG 플러그인을 선택해 활성화한 뒤 작업을 요청합니다.
   여러 단계의 요청은 작업으로 묶어 달라고 요청할 수 있습니다. **실행 로그**에서 작업을 펼쳐 결과를 확인하거나 **작업 중지**를 선택합니다. **요청 완료**는 현재 보관된 요청의 성공을 뜻하며 전체 목표의 완료를 보장하지 않습니다.
5. 수동승인이 필요한 요청은 **실행 로그**에서 **승인 후 실행** 또는 **거절**로 결정합니다.
6. 필요하면 **자동승인 켜기**를 선택하고, **실행 로그**에서 받은 요청과 결과를 확인합니다. .env 파일은 항상 차단됩니다.

실행 로그는 사용자 컴퓨터에 저장하며 화면에 최근 200개를 표시합니다. 상세 로그를 비운 요청의 중복 실행 방지 정보까지 포함해 내부에는 최대 1,000개를 보관합니다. 기간에 따른 자동 삭제는 없으며 새 요청이 없으면 기존 기록이 유지됩니다. 대기·실행 요청은 우선 표시하고, 한도를 넘긴 오래된 완료 요청의 내용·출력·요청 ID·중복 실행 방지 정보와 작업 집계는 삭제합니다. 완료 로그 비우기는 화면 밖의 완료 로그도 지우지만 대기·실행 요청은 보존하며, 중복 실행 방지 정보는 같은 1,000개 보관 한도 안에서 유지합니다. 중복 실행 방지 정보가 삭제된 뒤 같은 요청을 다시 보내면 재실행될 수 있으므로 실제 결과를 먼저 확인하고 삭제된 요청 ID는 재사용하지 마세요.

파일 읽기 도구가 반환한 원문은 실행 로그에 저장하지 않습니다. 파일 변경의 변경 전·후 내용은 처리 중에 저장하고, 완료·실패·거절·중지되면 삭제합니다. 명령 출력은 로그에 저장되므로 출력에 포함된 파일 내용도 남을 수 있습니다. WWG 기록 삭제는 이미 ChatGPT에 전달된 내용을 삭제하지 않습니다.

명령은 macOS에서 `sh`, Windows에서 프로필을 불러오지 않는 `PowerShell`을 사용합니다. Windows 파일 이동·삭제는 `Move-Item`, `Remove-Item`으로 실행합니다. Windows 명령은 보호 경로와 위험한 링크를 제외한 복사본에서 격리 실행한 뒤 결과를 원본에 반영합니다. 원본이 바뀌거나 결과에 보호 경로·링크가 생기면 반영을 거부하며, 결과 반영 전 명령 중지는 복사본의 변경을 버립니다. 많은 파일은 복사·검사 시간이 추가됩니다. `node`·`npm`·`npx`·`git`을 사용하는 명령에는 기본 경로의 런타임을 준비합니다.
