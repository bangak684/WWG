# WWG

웹 ChatGPT를 내 컴퓨터에 연결해 파일과 명령을 실행하는 앱입니다.

## 기능

- 웹 ChatGPT 맞춤형 MCP 서버 등록과 터널 연결
- 여러 접근 폴더에서 파일 읽기·생성·수정·삭제
- AI가 접근을 허용한 프로젝트·폴더 목록과 경로 조회
- macOS·Windows 명령 실행과 폴더 간 대량 파일 이동·삭제
- 받은 요청, 실행 결과, 차단 사유를 실행 로그에 표시하고 내부에 최대 1,000개 보관
- 여러 파일·명령 요청을 작업으로 묶고 상태 조회·중지
- 수동승인이 필요한 요청에만 승인·거절 버튼 표시
- 자동승인과 일시 정지, 실행 중인 명령 중지
- `.env*`와 허용 범위 밖 접근 차단
- 기존 OS 환경변수의 이름만 허용하고 요청한 변수만 전달
- macOS 메뉴 막대에서 연결·실행 로그·승인 방식 조작
- Windows 무설치형 EXE 또는 ZIP으로 실행

## 사용방법

### 1. 실행

[최신 버전 다운로드](https://github.com/bangak684/WWG/releases/latest)

[개인정보 및 데이터 처리 안내](PRIVACY.md)는 **접근 설정 → OS 환경변수 아래 → 개인정보 및 데이터 처리 안내**에서 펼쳐 볼 수 있습니다. 앱을 시작할 때 별도 확인 버튼을 누를 필요는 없습니다.

| 운영체제 | 실행 방법 |
|---|---|
| macOS Apple Silicon | DMG를 열고 **WWG.app**을 응용 프로그램 폴더로 옮깁니다. |
| Windows x64 | 무설치형 EXE를 바로 실행하거나 ZIP을 모두 풀고 **WWG.exe**를 실행합니다. |

macOS에서는 창을 닫아도 메뉴 막대에서 연결을 유지합니다. **WWG 열기**로 화면을 열고 **WWG 완전히 종료** 또는 `⌘Q`로 앱을 종료하세요.

Windows에서는 창을 닫으면 앱과 터널 연결, 실행 중인 명령이 모두 종료됩니다.

### 2. 접근 폴더 선택

상단의 **접근 폴더 → 선택**에서 사용할 폴더를 선택합니다. 여러 폴더를 한 번에 선택할 수 있습니다. 프로젝트 등록은 필요 없습니다.

ChatGPT에 **“WWG에서 접근할 수 있는 프로젝트 목록을 확인해줘”**라고 요청하면 허용한 프로젝트·폴더의 이름과 경로를 확인할 수 있습니다. AI는 조회한 프로젝트 ID와 상대 경로 또는 파일의 전체 경로로 작업할 수 있습니다.

**접근 설정**에서 폴더 접근을 해제할 수 있습니다. 접근을 해제하면 대기·실행 중인 요청을 중지하며 실제 파일은 삭제하지 않습니다. `.env*`는 승인 방식과 관계없이 차단됩니다.

### 3. 웹 ChatGPT 연결

1. **ChatGPT 연결**에서 OpenAI 터널과 런타임 API 키를 준비합니다. 터널은 사용할 ChatGPT 워크스페이스에 연결합니다.
2. 다운로드 안내로 `tunnel-client`를 설치하고 **설치 확인**을 누릅니다. WWG에 터널 ID와 API 키를 입력하고 **터널 연결**을 누릅니다.
3. 웹 ChatGPT의 **설정 → 보안 및 로그인**에서 개발자 모드를 켭니다. WWG의 **맞춤형 MCP 서버 만들기** 버튼으로 플러그인 페이지를 열고 **+ → 맞춤형 MCP 서버 만들기**를 선택합니다.
4. 이름은 **WWG**, 설명은 **내 컴퓨터의 파일·명령 실행**으로 입력합니다. **Connection → Tunnel**에서 WWG가 사용하는 터널을 선택하거나 **터널 ID 복사**로 복사한 ID를 입력합니다.
5. WWG에 **터널 연결됨**이 표시되면 웹에서 맞춤형 MCP 서버 생성을 완료하고 도구 목록을 확인합니다. 개인 플러그인 목록에서 등록한 WWG를 열고 아직 설치되지 않았다면 설치합니다.
6. 웹 ChatGPT 대화에서 **@WWG**를 입력하고 WWG 플러그인을 선택해 활성화합니다. 원하는 파일·명령 작업을 요청합니다.

맞춤형 MCP 서버 생성 화면은 터널 연결 전에도 열 수 있으며, 생성 완료와 사용에는 연결된 터널이 필요합니다. 연결 과정은 [공식 MCP 연결 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt)와 [Secure MCP Tunnel 안내](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)를 참고하세요.

**API 키는 WWG를 실행할 때마다 다시 입력해야 합니다.** WWG는 API 키를 저장하지 않습니다. 앱을 다시 실행한 뒤 **ChatGPT 연결**에서 API 키를 입력하고 **터널 연결**을 누르세요.

파일은 전체 경로로 요청하고, 명령은 실행할 폴더의 전체 경로를 지정하세요. WWG로 작업하는 동안에는 앱과 터널 연결을 유지하세요.

macOS 명령은 `sh`, Windows 명령은 프로필을 불러오지 않는 `PowerShell`을 사용합니다. ChatGPT가 WWG의 OS 정보를 확인하고 해당 OS에 맞는 명령을 실행합니다. Windows에서 파일을 이동·삭제할 때는 `Move-Item`, `Remove-Item`을 사용하세요.

Windows 명령은 보호 경로와 위험한 링크를 제외한 작업 복사본에서 격리 실행하고, 종료 후 변경을 원본에 반영합니다. 실행 중 원본이 바뀌면 덮어쓰지 않습니다. 새 보호 경로·링크가 생기거나 보호 경로가 들어 있는 폴더를 이동·삭제하면 반영을 거부합니다. 결과 반영 전에 명령을 중지하면 복사본의 변경을 버립니다. 파일이 많은 폴더는 복사·검사 시간이 추가됩니다. `node`·`npm`·`npx`·`git`을 사용하는 명령에는 기본 설치 경로의 런타임을 준비하며, 사용자 프로필과 `.env`는 불러오지 않습니다.

### 4. 승인과 실행 로그

기본은 **수동승인**입니다. 파일 조회는 바로 처리하고, 파일 변경·삭제와 명령은 **실행 로그**의 **승인 후 실행** 또는 **거절**로 결정합니다. 승인 버튼은 승인 대기 중인 요청에만 표시됩니다.

**자동승인 켜기**를 선택하면 허용한 폴더 안의 변경·명령을 추가 확인 없이 실행하며 승인 대기 중인 요청도 실행합니다. 확인창에서 **다음 실행에도 자동승인 유지**를 선택할 수 있습니다. **자동승인 끄기**는 실행을 중지하고 수동승인으로 전환합니다.

여러 단계의 요청은 ChatGPT에 **“이 요청들을 하나의 작업으로 묶어서 진행해줘”**라고 요청할 수 있습니다. **실행 로그**에서 작업 이름을 펼치면 관련 파일·명령 요청과 결과가 표시됩니다. **작업 중지**는 해당 작업의 대기 요청과 실행 중인 명령을 중지합니다. **요청 완료**는 현재 보관된 요청이 성공했다는 뜻이며 전체 목표의 완료를 보장하지 않습니다. 추가 요청을 같은 작업에 연결할 수 있습니다. 중지한 작업을 이어가려면 새 작업을 만드세요.

**일시 정지**는 요청 수신과 실행을 멈추며, 실행 로그의 **실행 중지**는 해당 요청만 중지합니다. 화면에는 최근 요청 200개를 표시하며 대기·실행 중인 요청을 우선 포함합니다. 기록은 사용자 컴퓨터에 저장하며, 상세 로그를 비운 요청의 중복 실행 방지 정보까지 포함해 내부에는 최대 1,000개를 보관합니다. 기간에 따른 자동 삭제는 없으며 새 요청이 없으면 기존 기록이 유지됩니다. 한도를 넘으면 오래된 완료 요청의 내용·출력·요청 ID·중복 실행 방지 정보·작업 집계를 삭제하며 재시작해도 복원하지 않습니다. 요청이 모두 삭제된 작업 묶음도 정리합니다. 작업 묶음은 최대 100개입니다. **완료 로그 비우기**는 화면 밖의 완료 로그도 비우고, 중복 실행 방지 정보는 같은 1,000개 보관 한도 안에서만 유지합니다. 중복 실행 방지 정보가 삭제된 뒤 같은 요청을 다시 보내면 재실행될 수 있습니다. 삭제된 요청 ID는 재사용하지 말고 실제 결과를 확인한 뒤 새 요청을 만드세요.

파일 읽기 도구가 반환한 원문은 실행 로그에 저장하지 않습니다. 파일 변경의 변경 전·후 내용은 처리 중에 저장하고, 완료·실패·거절·중지되면 삭제합니다. 명령 출력은 실행 로그에 저장되므로 출력에 포함된 파일 내용도 남을 수 있습니다. WWG에서 기록을 지워도 이미 ChatGPT에 전달된 내용은 삭제되지 않습니다.

### OS 환경변수

**접근 설정 → OS 환경변수**에 `API_TOKEN, DATABASE_URL`처럼 허용할 이름만 저장합니다. ChatGPT에는 필요한 변수 이름을 사용해 달라고 요청하세요. 값은 WWG를 실행한 OS 환경에서 가져오며 `.env` 파일은 불러오지 않습니다. 요청한 허용 변수만 명령에 전달하고 값은 실행 출력에서 숨깁니다.
